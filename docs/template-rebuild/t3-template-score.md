# T3 Template Score Standard

## Score Dimensions (0-10)

- space control
- composition control
- hierarchy control
- lighting control
- detail control
- semantic control
- stability

## Scoring Scale

- 0-2: invalid/weak control
- 3-5: partial control, unstable output
- 6-7: production-acceptable baseline
- 8-9: strong commercial control
- 10: benchmark-level deterministic control

## Dimension Rubric

1. Space Control: clarity of spatial relations and depth.
2. Composition Control: framing intent and subject placement stability.
3. Hierarchy Control: clear foreground-midground-background/object priority.
4. Lighting Control: direction/quality/mood consistency.
5. Detail Control: material/texture/fine detail retention.
6. Semantic Control: scene intent and narrative objective clarity.
7. Stability: repeatable structure under equivalent inputs.

## Release Threshold

Template must satisfy:

- total average score >= 6.0
- no single core dimension (space/composition/hierarchy/semantic) below 5
