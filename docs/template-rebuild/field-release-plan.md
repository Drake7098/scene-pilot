# 字段释放计划（Phase A1）

## 目标
把所有会直接影响生成结果的 hidden / pro / advanced 字段释放到可见编辑体系，仅保留系统内部字段继续隐藏。

## 释放范围
- 释放：影响画面、镜头、对象、背景、描述、状态、连续性的字段。
- 继续隐藏：`internal`、`debug`、`lint`、`audit`、`cache`、`legacy fallback only`、`provider adapter only`。

## 执行规则
1. 模板与手动编辑共享同一字段能力，不再允许“模板偷偷激活隐藏字段”。
2. 字段释放只调整可见层与分组层，不改变字段语义。
3. 冲突字段必须保留显示，不得通过隐藏规避冲突。
4. 字段释放顺序：先可见，再分层，再冲突提示。

## 验收清单
1. 可影响画面的字段可在 UI 中编辑。
2. 模板注入与手动编辑一致可见。
3. 隐藏字段仅保留系统内部字段。
4. 无字段因冲突被“直接消失”。
