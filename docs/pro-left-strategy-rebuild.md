# Pro 左侧策略系统重建

> 为什么左侧是本轮核心，为什么要拆成 Director / Camera / Lighting

---

## 一、为什么左侧是本轮核心

模板驱动工作流的核心价值不是「让用户再写很多字」，而是：

> 用户用很少的选择，就能把结构和专业拍摄感拉起来。

用户从模板工作台选模板、回到 Pro 后，**第一个决策点**在左侧：当前分镜的策略、镜头、光。

- **右侧**（PropsPanel）：对象细节、构图、背景——偏「填充内容」
- **左侧**（Sidebar）：策略、镜头、光——偏「设定方向」

方向错了，再改多少细节都难救；方向对了，少量微调就能出片。所以左侧才是**创作主控制**所在。

---

## 二、为什么不能继续用 Scene Strategy 大杂烩

当前「场景策略」把以下内容混在一起：

- 入镜/出镜方向
- 对象继承
- 一键预设（经典模式）
- 景别 / 镜头运动
- 导演级风格包
- 镜头语言 / 画面语言
- 衔接方式
- （镜头·光单独一块，但层级平级）

问题在于：

1. **没有主次**：用户不知道先改什么
2. **专业能力被稀释**：镜头语言、导演包本应是高杠杆，却和底层参数并列
3. **概念混杂**：入镜/出镜是连续性概念，景别/运动是镜头概念，导演包是气质概念，全塞在「策略」里

因此需要拆开，按**导演意图 → 镜头任务 → 光与氛围**分层。

---

## 三、为什么要拆成 Director / Camera / Lighting

### 1. Director Control（导演控制）

**本质**：用「导演意图」替代一堆底层参数，快速改变结果气质。

用户想要的不是改 `key_dir`、`mood`、`movement`，而是：

- 更像广告
- 更像短剧
- 更像电影
- 更像对话场面
- 更像人物出场
- 更像情绪爆发

Director Control 提供的就是这类**目标导向预设**，对应多组 shot / movement / language / lighting / pacing 的组合。

### 2. Camera Control（镜头控制）

**本质**：把 shot、movement、镜头语言、转场，整合成清晰的镜头系统。

- **镜头任务**（一级）：建立空间、人物出场、双人对话、跟随叙事、产品展示、情绪特写等
- **景别**（二级）：特写、近景、中景、全景、远景
- **运动**（二级）：静止、推近、拉远、横移、跟拍、环绕、升降
- **镜头语言**（一级）：克制写实、广告精致、电影叙事、社媒直给、情绪压迫、动漫戏剧化等
- **转场**（多镜时）：cut、dissolve、match cut 等

镜头语言不应埋深，应作为一级可见字段。

### 3. Lighting / Atmosphere（光与氛围）

**本质**：从「拍摄思维」组织光，而不是零散参数。

- **时间氛围**：白天、黄昏、夜晚、清晨、阴天、室内人造光
- **主光方向**：正面、侧光、逆光、顶光、边缘光、柔和漫射
- **氛围强度**：自然、干净商业、戏剧化、压迫感、温暖、冷感、高级感、悬疑感
- **光影风格包**：商业棚拍、电影低照度、明亮社媒、霓虹都市、高级产品光、动漫高对比等

## 四、最终左侧五大块

| 模块 | 职责 |
|------|------|
| Current Template | 当前模板身份、family/variant、更换模板、回跳工作台 |
| Scenes / Continuity | 场景列表、连续关系、当前镜头在序列中的位置 |
| **Director Control** | 导演预设，目标导向的气质控制 |
| **Camera Control** | 镜头任务、景别、运动、镜头语言、转场 |
| **Lighting / Atmosphere** | 时间氛围、主光方向、氛围强度、光影风格包 |

Scene Strategy 不再作为独立大块存在，其内容拆入 Director / Camera / Lighting。

---

## 五、与右侧的边界

| 左侧 | 右侧 |
|------|------|
| 分镜策略、镜头意图、光与氛围 | 对象属性、构图、背景 |
| 方向型、少选项、高杠杆 | 细节型、填充内容 |
| 属于「创作主控制」 | 属于「对象与场景细节」 |

Platform Mode 不属于创作主控制，应下沉到导出区。
