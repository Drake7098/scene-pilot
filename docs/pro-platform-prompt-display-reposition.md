# Platform Mode 与 Prompt 区重新定位

> Platform Mode 为什么下沉，Prompt 区为什么降级为结果预览，正确展示方式是什么

**实现参考**：左右分屏实现详见 `prompt-preview-and-export-split.md`、`prompt-readonly-positioning.md`、`export-primary-actions-redesign.md`。

---

## 一、Platform Mode 为什么下沉

### 定位问题

Platform Mode 控制的是：

- 目标平台（fal、Runway 等）
- 导出方式（仅提示词 / 提示词+参考图）
- 结构强度、坐标策略等

这些属于**导出/平台适配**，不是**创作主控制**。

### 用户决策顺序

1. **创作**：选模板 → 调导演/镜头/光 → 填主体
2. **导出**：选平台 → 选导出方式 → 复制/下载

Platform Mode 属于第 2 步，不应占用第 1 步的核心位置。

### 正确位置

- **放到 ExportPanel 附近**：作为导出区内的「平台策略」
- **或**：作为导出弹窗/面板中的「高级平台策略」
- **默认**：折叠或轻量展示
- **强调时机**：用户点击复制、导出、切平台时

### 与右侧 PropsPanel 的关系

- **当前**：Platform Mode 在右侧 PropsPanel，与 Template Slots、Scene Background、Object Properties 并列
- **调整后**：从 PropsPanel 移除，移入 ExportPanel 或导出相关区域
- **原则**：右侧聚焦对象与场景细节，不承载平台/导出策略

## 二、Prompt 区为什么降级为结果预览

### 定位问题

Prompt 区不应再承担「主编辑入口」：

- 产品卖的是**结构**，不是又一个 prompt 编辑器
- 若用户要靠改 prompt 才能出好结果，说明前面的结构和策略层没做好
- Prompt 区应是**观察/验证**层，不是**主要创作**层

### 正确定位

| 主定位 | 非主定位 |
|--------|----------|
| 编译结果预览 | 不鼓励直接在这里主编辑 |
| 导出结果观察 | 不替代 Template Slots / Director / Camera / Lighting |
| 冲突验证区 | 不承担创作主路径 |

### 保留能力

- 高级用户查看完整 prompt
- 复制、导出
- 冲突跳转
- 平台导出方式展示

## 三、正确展示方式

### Prompt 区

#### 默认

- 显示**简洁版 prompt 摘要**（如首段或结构标签）
- 显示**结构标签**（如当前平台、导出范围）
- 显示**冲突摘要**（如有）
- 显示**当前平台/导出方式**

#### 展开后

- 完整 prompt 文本
- 完整机器语言块（如有）
- 复制、导出按钮

#### 原则

- 不默认让用户面对一大块 prompt 文本
- 强调「这是系统编译结果」，不是建议反复手改的区域

### Platform Mode

#### 在导出区的展示

- 与「复制」「导出」同区
- 可折叠为「平台策略」或「目标平台」
- 展开后显示：当前平台、推荐平台、导出方式、结构提示

#### 原则

- 保留全部能力
- 不占创作主路径
- 在用户准备导出时再强调
