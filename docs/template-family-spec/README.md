# Template Family Spec 目录

40 个 family 的结构规格定义，用于后续生成 600 模板。**不是 payload**，是规格定义。

## 输出摘要

| 项目 | 数量 |
|------|------|
| **family 数量** | 40 |
| **scene 范围** | 1～6（single: 1；continuous: 2～4；multi_cam: 3～6） |
| **支持 advanced 数量** | 8 个 advancedTag 类型（advanced_camera, advanced_lighting, director_preset, continuity, multi_object, cinematic_mode, drama_mode, anime_mode） |
