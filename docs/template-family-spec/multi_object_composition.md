# multi_object_composition | 多对象构图

## familyId
`multi_object_composition`

## 支持 mediaType
- image

## 支持 storyPlan
- single

## 默认 sceneCount
1

## 默认 shot 范围
- ms, fs, ls

## 默认 movement 范围
- static

## 默认 cameraLanguage 范围
- commercial_ad, cinematic_narrative

## 默认 lighting 范围
- time: day
- keyDir: top_left
- mood: bright
- lightingPack: natural_skin_readability

## 默认 composition 范围
- depth_split, clean_layering, left_right_standoff

## 默认 objects 类型
- character, product, prop（≥3）

## 允许 advancedTags
- advanced_camera, multi_object

## 允许 variants
- free_starter, basic_wide, basic_medium, basic_close
- vertical_9_16, horizontal_16_9, social_fast
- cinematic, multi_object, advanced_motion
