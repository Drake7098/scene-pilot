# 1. Scene 字段完整表

## Scene
| 字段名 | 类型 | 可选值/说明 |
|---|---|---|
| id | string | 任意 |
| name | string | 任意 |
| index | number \| undefined | 任意 |
| layoutLocked | boolean \| undefined | true/false |
| aspectRatio | "1:1" \| "4:3" \| "16:9" \| "9:16" \| "21:9" \| undefined | 见比例枚举 |
| backgroundRef | SceneRefMeta \| undefined | `{id,name,mime,size,updatedAt}` |
| inheritFromPrevious | boolean \| undefined | true/false |
| inheritBgRefFromPrevious | boolean \| undefined | true/false |
| inheritObjectRefsFromPrevious | "off" \| "identity_only" \| "all" \| undefined | 继承模式 |
| transitionType | "cut" \| "reverse_angle" \| "camera_continues" \| "dissolve" \| "time_jump" \| undefined | 转场 |
| duration_s | number | 秒 |
| cameraPreset | string \| undefined | 任意 |
| shotNote | string \| undefined | 任意 |
| entryDir | "N"\|"NE"\|"E"\|"SE"\|"S"\|"SW"\|"W"\|"NW" \| undefined | 进入方向 |
| exitDir | "N"\|"NE"\|"E"\|"SE"\|"S"\|"SW"\|"W"\|"NW" \| undefined | 退出方向 |
| camera | Camera | `{shot,movement,keyframes[]}` |
| lighting | Lighting | `{time,key_dir,mood}` |
| layers | Layer[] | 对象数组 |
| config.mediaMode | "image" \| "video" \| undefined | 输出媒体 |
| config.compiler | "v1" \| "v2" \| "v3" \| undefined | 编译器 |
| config.sceneTier | "indoor" \| "small_plaza" \| "open_space" \| undefined | 场景层级 |
| config.v2Mode | "strict" \| "short" \| undefined | v2模式 |
| config.stability | "off" \| "standard" \| "strict" \| undefined | 稳定性 |
| notes | string | marker 容器 |
